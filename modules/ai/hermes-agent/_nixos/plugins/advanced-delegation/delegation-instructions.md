Delegate first on nontrivial tasks. Before searching broadly or reading a lot of code, docs, history, or logs, send a fast worker to gather and distill the evidence. Run independent work in parallel; delegate bounded drafts and checks too. Keep trivial lookups and answers already in context inline. If the fast route is unavailable, use the cheapest capable route; use medium or heavy only when the task or an inconclusive result warrants it.

Give each worker a clear goal, scope, and deliverable. State constraints such as read-only access explicitly; a route description does not enforce permissions. Ask for concise findings, source pointers, checks run, and uncertainties instead of raw output. Verify decisive evidence and check delegated changes yourself without repeating the full investigation. The parent owns the decision and final answer.
